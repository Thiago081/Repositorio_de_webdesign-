## 📚 Material Complementar — Web Design

Materiais de apoio disponibilizados pelo professor para consulta e prática ao longo da disciplina:

* 🌐 **[Repositório da Disciplina (Web Design)](https://github.com/deivisontakatu/aula-web-design)** — Ementa, objetivos, competências e organização geral das aulas.
* 🧱 **[HTML](https://github.com/deivisontakatu/aula-html)** — Fundamentos, estrutura de documentos, tags semânticas, links, imagens e SEO básico.
* 🎨 **[CSS](https://github.com/deivisontakatu/aula-css)** — Seletores, cores, tipografia, box model, Flexbox, Grid e responsividade.
* 🟨 **[JavaScript](https://github.com/deivisontakatu/aula-javascript)** — Lógica de programação, manipulação de DOM, eventos, formulários, LocalStorage e APIs.
* 🔄 **[Scrum](https://github.com/deivisontakatu/aula-scrum)** — Guia sobre o framework ágil, papéis do time, eventos e artefatos.
* 📝 **[Documentação de Software](https://github.com/deivisontakatu/aula-documentacao-software)** — Boas práticas para estruturar projetos, criar arquivos README e colaborar no GitHub.
