# 🌐 WebDesign Hub — Central de Projetos e Estudos

Bem-vindo ao repositório centralizador da disciplina de **Web Design**. Este espaço atua como um portal de documentação para reunir materiais de apoio e mapear a evolução prática dos projetos desenvolvidos ao longo do semestre.

> 🤝 **Nota sobre Colaboração:** Os projetos listados neste índice foram desenvolvidos em equipe. Por questões de organização do fluxo de trabalho, os repositórios originais e os deploys foram hospedados na conta do colega de grupo que colaborou diretamente na construção dos códigos.

---

## 📌 Propósito do Repositório

* **Acervo Didático:** Reunir slides, anotações de aula e códigos-base disponibilizados durante a disciplina.
* **Mapa de Projetos:** Funcionar como um diretório rápido para navegar entre os laboratórios práticos e aplicações web criadas pelo time.
